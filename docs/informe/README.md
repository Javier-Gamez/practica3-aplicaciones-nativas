# Informe de la práctica — estructura sugerida

Arma el informe final (Word/PDF) con estas secciones, en este orden (según el enunciado):

1. **Portada** — nombre completo y boleta de todos los integrantes, asignatura, profesor, fecha.
2. **Introducción** — resumen de los 5 ejercicios y el entorno utilizado (macOS-Docker vs Mac física).
3. **Desarrollo** — por cada ejercicio: descripción técnica + capturas de pantalla.
   - Usa las capturas que se van generando en cada carpeta `ejercicioN-*/`.
   - Para el Ejercicio 4, las capturas del emulador Android probado en esta máquina están en
     `docs/evidencia/ejercicio4/` (agrégalas ahí).
4. **Pruebas realizadas** — qué se probó en qué dispositivo/simulador/emulador, y resultados.
5. **Bitácora de trabajo** — copia o enlaza [`docs/bitacora.md`](../bitacora.md).
6. **Conclusiones** — reflexión sobre desarrollo iOS, ecosistema Apple, macOS-Docker, y la
   comparación Flutter vs Kotlin Multiplatform (retoma la tabla del punto 5.5).
7. **Bibliografía** — formato APA.
